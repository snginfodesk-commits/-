למעלה ורצים בשלושה שלבים

הדרישה היחידה היא Python 3.9+. מצב ההדגמה עובד בלי שום אישורי API.

התקנה של תלויות

צרו סביבה וירטואלית והתקינו את הספריות הנדרשות.

pip install -r requirements.txt

הגדרת אישורים

העתיקו את קובץ הדוגמה והוסיפו את ה-Access Token ומזהה חשבון המודעות.

cp .env.example .env

הרצת הדשבורד

פתחו את האפליקציה בכתובת localhost:8501 והפעילו את מצב ההדגמה.

streamlit run app.py

מוכנים לראות את הקמפיינים שלכם בבהירות?

הריצו את הדשבורד מקומית עם נתוני דמו — בלי שום צורך בחשבון פייסבוק.
