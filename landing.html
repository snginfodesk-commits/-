Built-in health checks

Every ad set is automatically scored against four diagnostic rules so you spend less time in spreadsheets.

Flag Triggered When Recommended Action
High Fatigue Frequency > 2.5 and CTR below average Refresh creative, test new angles
Page Load / High Bounce LP View Rate < 60% of clicks Check page speed and mobile experience
LP / Offer Mismatch CTR > 1.2% but Conv. Rate < 5% Align landing page with ad messaging
Ready to Scale CPL 20%+ below target, Frequency < 1.5 Increase budget incrementally

Up and running in three steps

Python 3.9+ is the only prerequisite. Demo mode works without API credentials.

Install dependencies

Create a virtual environment and install the requirements.

pip install -r requirements.txt

Configure credentials

Copy the example env file and add your Facebook access token and ad account ID.

cp .env.example .env

Launch the dashboard

Open the app at localhost:8501 and toggle demo data on first run.

streamlit run app.py

Ready to see your ads more clearly?

Run the dashboard locally with demo data — no Facebook account required.
