# תקציב הבית

אתר עצמאי לניהול תקציב משפחתי: תכנון חודשי, רישום הוצאות והכנסות, ומעקב חודשי ושנתי.
כל משתמש נרשם עם אימייל וסיסמה ורואה רק את הנתונים של עצמו.

## מה יש כאן

| קובץ | תפקיד |
|---|---|
| `index.html` | האתר כולו (עיצוב, מסכים ולוגיקה) |
| `config.js` | כתובת ומפתח ציבורי של פרויקט ה-Supabase |
| `supabase/schema.sql` | הטבלה וכללי ההרשאות במסד הנתונים |

אין שלב בנייה ואין תלויות להתקנה. כל עוד `config.js` ריק, האתר רץ ב"מצב הדגמה" בלי הרשמה ושומר נתונים רק בדפדפן.

## הקמה (פעם אחת)

### 1. מסד נתונים ומשתמשים: Supabase

1. פותחים חשבון ב-supabase.com ויוצרים פרויקט חדש.
2. ב-SQL Editor מדביקים את התוכן של `supabase/schema.sql` ולוחצים Run.
3. ב-Project Settings ← API מעתיקים את ה-Project URL ואת המפתח `anon public` לתוך `config.js`.

### 2. אירוח האתר

כל שירות אירוח סטטי מתאים. לדוגמה ב-Netlify: Add new site ← Import from GitHub, בוחרים את המאגר הזה,
ב-Base directory כותבים `budget-app`, משאירים את Build command ריק וב-Publish directory כותבים `budget-app`.

### 3. חיבור בין השניים

ב-Supabase ← Authentication ← URL Configuration מזינים את כתובת האתר ב-Site URL וגם ב-Redirect URLs.
בלי זה, הקישורים במיילים של אישור הרשמה ואיפוס סיסמה לא יחזרו לאתר.

## לפני שפותחים לקהל רחב

- **מיילים:** שירות המיילים המובנה של Supabase מוגבל למספר קטן של הודעות בשעה ומיועד לבדיקות.
  לשימוש אמיתי מגדירים SMTP משלכם ב-Authentication ← Emails (למשל Brevo).
- **כניסה עם Google (רשות):** מפעילים את הספק ב-Authentication ← Providers ומשנים ב-`config.js` את `googleLogin` ל-`true`.
- **נוסח המיילים:** אפשר לתרגם לעברית ב-Authentication ← Emails ← Templates.

## מבנה הנתונים

טבלה אחת, `budget_docs`, עם שורה לכל מסמך של כל משתמש:
`main` מחזיק את הקטגוריות והתכנון, ו-`m-YYYY-MM` מחזיק את התנועות של חודש אחד.
כלל ה-Row Level Security מאפשר לכל משתמש לקרוא ולכתוב רק שורות שה-`user_id` שלהן הוא שלו.
